# labels/

Hand-off files for the human annotation (R3.4), generated by `src/process/export_labels.py`. The original workbooks are kept in `annotation/`.

| File | Content |
|---|---|
| `sample_for_annotation.csv` | 30 calibration items plus 360 formal sample items, i.e. the blind texts the annotators saw, with split (calibration/dev/test) |
| `sample_key.csv` | Source, stratum, date, URL and sampling weight for each item; not shown to annotators |
| `sampling_design.json`, `sampling_frame_sizes.csv` | Sampling design (seed 20261015) and the sampling frame size of each cell |
| `annotator_A.csv`, `annotator_B.csv` | The independent labels of each of the two human annotators (the project lead states that both were done entirely by hand, without AI or scripts) |
| `annotator_A_time_log.csv`, `annotator_B_time_log.csv` | Time logs, kept as they are; B's log was filled in afterwards as an estimate, not measured |
| `agreement_summary.csv`, `confusion_matrices.csv` | Cohen's κ, Krippendorff's α and raw agreement rate, broken down by all/dev/test/national/local/social |
| `adjudication_log.xlsx` | Adjudication results and written reasons for the 593 disagreement items |
| `adjudicated.csv`, `adjudicated_calibration.csv` | Gold standard v1 |
| `gold_overview.json` | Adjudication statistics |
| `ai/` | Reserved for LLM labeling output, named `<model_id>__<prompt_version>.jsonl` |

Evaluation rules (confirmed by the user on 2026-10-16):
- The 32 gold-standard items with relevant=unsure (8 in the development set, 24 in the test set) are excluded from the precision and recall of relevant and their count is reported separately; the other dimensions are evaluated as usual.
- The prompt is tuned only on the 100-item development set; once frozen, it is evaluated once on the 260-item test set.
