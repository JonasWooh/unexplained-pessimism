# 任务：期末项目数据收集

请按照《数据收集方案》（data_collection_plan.md）为本项目收集原始数据。开始前先完整阅读这份方案，并阅读《任务指导清单》（task_guide.md）了解项目背景。你只负责收集数据和检查完整性，不做分析或标注。

**密钥**：FRED、纽约时报、Guardian、Media Cloud、YouTube 的 API key 保存在我本地的文本文件 `<填写路径>` 中。由代码在运行时读取，不要在输出中显示，也不要复制到其他文件、代码或日志里。

**要求**：
1. 先测试各数据网站能否访问。访问不了的记录下来告诉我，不要设法绕过。
2. 按方案中的顺序收集：先收集调查数据和宏观数据，再收集新闻和社交媒体数据。YouTube 有每日配额限制，第一天就开始。
3. 宏观数据要保留全部历史版本和发布日期。
4. 每份数据都要记录来源、下载时间和覆盖期。原始文件下载后不要修改。
5. 方案里标注“需核实”的地方，请实际核实。与方案不符时，按合理的方式继续，并记录你的决定。
6. 教授的 Excel 只用来核对，重点确认其中的 “PCE YoY” 是总体 PCE 还是核心 PCE。
7. Reddit 暂不下载，等我确认。

**红线**：只收集真实数据，不得编造或凭记忆填写；拿不到的记为缺失并说明原因。遵守各网站的使用条款和配额。社交媒体数据不保存用户名等个人信息。

**完成后**，给我一份简短汇报：每个数据集的状态、覆盖期、条目数、遇到的问题，以及需要我决定的事项。
